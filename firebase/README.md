# Firebase 보안 규칙 (wise 경로)

수업 앱이 쓰는 실시간 DB(`remind-c2610`)의 `wise` 경로에 넣을 규칙입니다.
같은 DB를 다른 앱도 쓰고 있을 수 있으므로 규칙 전체를 바꾸지 않고 `wise` 부분만 바꿉니다.

## 넣는 순서

1. Firebase 콘솔에서 `remind-c2610` 프로젝트를 엽니다.
2. 왼쪽 메뉴의 Realtime Database에서 '규칙' 탭을 누릅니다.
3. `"rules": { ... }` 안에 있는 `"wise": { ... }` 묶음을 `wise-rules.json`의 `"wise": { ... }` 묶음으로 바꿉니다.
   `wise` 묶음이 없으면 `"rules": {` 다음 줄에 넣고, 다른 항목과는 쉼표로 구분합니다.
4. '게시'를 누릅니다.

## 규칙이 막는 것

| 경로 | 읽기 | 쓰기 |
|---|---|---|
| `meta` (방 정보) | 막음 | 방을 처음 만들 때 한 번만 |
| `meta/locked` | 막음 | 잠그기(`true`)만 허용, 풀기와 지우기는 거부 |
| `entries` (학생 제출) | 허용 | 새 제출 추가만 허용, 남의 제출 수정·삭제는 거부 |
| `votes` (투표) | 허용 | 추가만 허용 |
| `approve` (교사 확인 도장) | 허용 | 참·거짓 값만 허용 |

예전에 만든 방의 `meta`에는 교사 비밀번호 원문이 남아 있습니다. 규칙을 넣으면 `meta`를 읽을 수 없게 되어 밖으로 보이지 않습니다.

학생 제출(`entries`)은 수업 화면에서 학급 친구들의 결과를 함께 보여 주기 때문에 읽기를 열어 둡니다.
대신 앱에서 실명, 학번, 연락처를 받지 않습니다.
