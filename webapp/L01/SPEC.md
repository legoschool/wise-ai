# 1차시 웹앱 구성안 : 데이터 실험실

- 차시 : 1차시 AI는 어떻게 똑똑해질까
- 학습 문제 : AI가 어떻게 배우는지 알아보고, AI가 우리의 생각을 도와주는지 대신해 주는지 생각해 봅시다.
- slug : `data-lab`
- 산출 경로 : `out/webapp/L01/index.html`

## 무엇을 하는 앱인가

AI 학생 몽이의 선생님이 되어 카드에 이름표를 붙입니다. 붙인 이름표로 브라우저 안에서 진짜 모델이 학습하고, 한쪽 카드를 줄이면 정확도가 무너지는 것을 눈으로 봅니다.

## 화면

1. 이야기 : AI 학생 몽이를 맡게 된 사연을 읽습니다.
2. 교무실 : 오늘 할 다섯 교시를 한눈에 봅니다. 끝낸 교시에 도장이 찍힙니다.
3. 나라면 어떻게 맞힐까 : AI를 켜기 전에 사람이 무엇을 보고 판단하는지 먼저 말로 꺼냅니다.
4. 이름표 붙이기 : 카드 스무 장에 강아지와 고양이 이름표를 붙입니다. 이것이 학습 데이터가 됩니다.
5. 학습과 시험 : 학습 단추를 누르면 브라우저 안에서 진짜 모델이 학습합니다. 시험 카드로 정확도를 재고 무엇을 근거로 삼았는지 막대로 봅니다.
6. 편식 실험 : 한쪽 카드를 줄여 다시 학습시킵니다. 정확도가 떨어지고 어떤 카드를 틀리게 되는지 눈으로 봅니다.
7. 역할 나누기 : 수업에서 있었던 일을 사람 칸과 AI 칸으로 나눕니다.

## 교사 화면

학급 평균 정확도, 데이터를 줄였을 때 평균 정확도, 라벨이 갈린 카드, 배움 문장 모음

## 이 앱만의 규칙

외부 라이브러리 없이 브라우저 안에서 도는 분류기다. 인터넷이 끊겨도 학습과 시험은 그대로 된다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/data-lab/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 정확도 경쟁으로 흐르지 않게 한다. 틀린 까닭을 데이터에서 찾는 것이 목표다.
- 라벨이 갈린 카드는 누가 맞았는지 가리지 않고, 사람마다 다르게 볼 수 있음을 짚는다.
- 개인정보가 담긴 사진은 쓰지 않는다. 이 앱은 사진을 올릴 수 없게 만들었다.

## 기기가 없을 때

기기가 부족하면 교사 화면 하나로 함께 진행한다. 인쇄한 카드 20장에 모둠이 이름표를 붙이고, 교사가 앞에서 학습과 시험을 눌러 결과를 함께 본다.
