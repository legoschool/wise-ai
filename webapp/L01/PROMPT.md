# 1차시 웹앱 제작 프롬프트 : 데이터 실험실

> 이 프롬프트 자체가 산출물이다. 선생님이 각자 고쳐 쓸 수 있도록 통째로 복사해 붙여 넣게 만들었다.
> 아래 코드 블록을 AI 도구에 그대로 붙여 넣으면 같은 앱이 다시 만들어진다.

---

```
초등 5·6학년 수업에서 쓸 웹앱을 만들어 줘.
HTML 파일 하나로 끝나야 하고, 외부 라이브러리나 CDN을 절대 참조하지 마.
Google Sites 의 소스 코드 삽입 기능에 그대로 붙여 넣을 것이다.

[수업 맥락]
1차시 AI는 어떻게 똑똑해질까
학습 문제 : AI가 어떻게 배우는지 알아보고, AI가 우리의 생각을 도와주는지 대신해 주는지 생각해 봅시다.
앱 이름 : 데이터 실험실
하는 일 : AI 학생 몽이의 선생님이 되어 카드에 이름표를 붙입니다. 붙인 이름표로 브라우저 안에서 진짜 모델이 학습하고, 한쪽 카드를 줄이면 정확도가 무너지는 것을 눈으로 봅니다.

[화면]
1. 이야기 : AI 학생 몽이를 맡게 된 사연을 읽습니다. 읽고 나서 "몽이에게 무엇부터 해 줄까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 교무실 : 오늘 할 다섯 교시를 한눈에 봅니다. 끝낸 교시에 도장이 찍힙니다.
3. 나라면 어떻게 맞힐까 : AI를 켜기 전에 사람이 무엇을 보고 판단하는지 먼저 말로 꺼냅니다.
4. 이름표 붙이기 : 카드 스무 장에 강아지와 고양이 이름표를 붙입니다. 이것이 학습 데이터가 됩니다.
5. 학습과 시험 : 학습 단추를 누르면 브라우저 안에서 진짜 모델이 학습합니다. 시험 카드로 정확도를 재고 무엇을 근거로 삼았는지 막대로 봅니다.
6. 편식 실험 : 한쪽 카드를 줄여 다시 학습시킵니다. 정확도가 떨어지고 어떤 카드를 틀리게 되는지 눈으로 봅니다.
7. 역할 나누기 : 수업에서 있었던 일을 사람 칸과 AI 칸으로 나눕니다.

[반드시 지킬 것]
1. 방 코드 6자리 + 비밀번호 4자리 + 닉네임으로 입장한다.
   방 코드 옆에 복사 버튼을 반드시 둔다.
2. 방 코드 없이 들어가는 '혼자 체험해 보기' 경로를 둔다.
   혼자 체험은 서버에 쓰지 않고 이 기기에만 저장한다.
3. 닉네임 중복을 막지 마라. 같은 닉네임이면 기존 기록을 이어받게 한다.
4. 교사가 화면을 닫아도 방이 사라지면 안 된다. 방 상태는 서버에 남는다.
5. 교사 화면에 제출 현황, 집계, CSV 내려받기, 방 잠그기를 둔다.
6. 실명, 학번, 연락처, 이메일을 묻지 마라. 사진 업로드 기능을 넣지 마라.
7. 글자 16px 이상, 누르는 곳은 44px 이상. 태블릿에서 손가락으로 쓴다.
8. 색만으로 뜻을 구분하지 마라. 색과 글자를 함께 쓴다.
9. 밝은 배경 하나로 통일한다. 교실 프로젝터에서 어두운 화면은 안 보인다.
10. 가로 스크롤이 생기면 안 된다. 넓은 표는 자체 스크롤 상자에 넣는다.
11. 정규식에 역슬래시 이스케이프(\d, \s, \w)를 쓰지 마라.
    [0-9], [ \t], [A-Za-z0-9_] 처럼 문자 클래스로 써라.
    Apps Script 로 옮길 때 역슬래시가 깨진다.

[데이터 저장]
Firebase 실시간 DB 를 REST 로 직접 호출한다. SDK 를 붙이지 마라.
주소 : https://remind-c2610-default-rtdb.firebaseio.com
경로 : /wise/data-lab/<방코드>/entries
실시간 갱신은 3초 폴링으로 한다. SSE 스트리밍은 학교망에서 끊긴다.
교사 비밀번호는 원문으로 저장하지 마라. 방 코드와 함께 SHA-256 으로 바꾼 값만 meta 에 남긴다.

같은 기록을 Google Sheets 에도 백업한다.
시트 : 선생님이 만든 백업 시트의 ID 를 여기에 넣는다.
Apps Script 웹앱 주소로 fetch POST 하되 mode 는 no-cors,
Content-Type 은 text/plain 으로 보낸다. 응답을 읽지 마라.
백업이 실패해도 학생 화면이 멈추면 안 된다. catch 로 삼키고 넘어가라.

[저장 형태]
{ "nick": "", "group": "", "app": "data-lab", "room": "", "at": 0, "payload": {} }
payload 안에만 이 차시 고유 내용을 넣는다.

[안전 문구]
입장 화면에 이 문구를 둔다.
  이름, 사진, 친구 이야기 같은 개인정보는 넣지 않아요.

[말투]
학생에게 보이는 문장은 초등 5·6학년이 읽는 문장으로 써라.
한 문장 40자 이내, 존댓말 청유형으로 쓴다.
em dash 를 쓰지 마라.
```

## 고쳐 쓰는 법

- 카드나 항목을 바꾸려면 위 프롬프트의 `[화면]` 부분을 고쳐 다시 돌린다.
- 우리 학교 상황에 맞춰 문구를 바꾸려면 `[수업 맥락]` 만 바꾸면 된다.
- 만들어진 파일은 Google Sites 에서 `삽입 → 소스 코드 삽입` 으로 붙여 넣는다.
