# 2차시 웹앱 구성안 : AI 검증 실험실

- 차시 : 2차시 AI도 틀린다, 환각과 검증
- 학습 문제 : AI의 답이 정말 맞는지 확인하는 방법을 찾아봅시다.
- slug : `verify-lab`
- 산출 경로 : `out/webapp/L02/index.html`

## 무엇을 하는 앱인가

검증관이 되어 몽이의 답을 심사합니다. 같은 질문에 두 도구가 내놓은 답을 나란히 놓고 다른 곳을 찾은 뒤, 앱 안에 든 근거 자료와 대조해 무엇이 환각이었는지 판정합니다.

## 화면

1. 이야기 : 몽이가 자신 있게 내놓은 답을 심사하러 검증소에 들어갑니다. 읽고 나서 "몽이가 자신감 98%로 답했어요. 어떻게 할까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 검증소 : 오늘 지나갈 검증 절차를 한눈에 봅니다.
3. 훈련소 : 그럴듯하게 쓰인 답 하나를 놓고 믿을지 말지 먼저 투표합니다. 확인하기 전에는 사람도 속는다는 것을 겪습니다.
4. 검증실 : 같은 질문에 두 도구가 내놓은 답을 나란히 놓고 다른 곳을 찾습니다. 앱 안에 든 근거 자료와 대조해 판정합니다.
5. 환각 사냥 : 찾아낸 환각을 카드에 적습니다. 무엇이 틀렸는지와 어떻게 확인했는지를 함께 씁니다.
6. 우리 반 판정 : 내 판정과 실제 판정을 맞춰 보고 학급 집계를 함께 봅니다.
7. 검증관 카드 : 오늘 배운 것을 한 문장으로 남기고 검증관 카드를 받습니다.

## 교사 화면

문항별 판정 분포, 학급 정답률, 학생이 만든 환각 사례 카드 모음, 배움 문장

## 이 앱만의 규칙

생성형 AI 계정이 없어도 돌아간다. 교사가 미리 검증한 답변 세트가 앱 안에 들어 있어서 학생이 실제 서비스에 질문을 넣지 않는다. 개인 이름을 넣어 검색할 일도 없다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/verify-lab/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 사실 확인이 가능한 질문으로만 한정한다. 이 앱은 그런 질문 다섯 개만 담고 있다.
- 개인 이름을 넣어 검색하지 않는다. 이 앱에서는 학생이 직접 질문을 넣지 않는다.
- 특정 서비스 비방으로 흐르지 않게 한다. 도구 이름을 가 나로만 적었다.
- 답이 갈리는 문항은 질문이 흐릿해서 갈린다는 점을 짚는다. 틀린 것과 다른 것은 다르다.

## 기기가 없을 때

기기가 부족하면 교사 화면 하나로 함께 진행한다. 두 답과 근거 자료를 인쇄해 모둠에 나눠 주고 같은 순서로 대조하면 된다.
