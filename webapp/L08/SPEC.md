# 8차시 웹앱 구성안 : 약속 선포 게시판

- 차시 : 8차시 우리 반 AI 약속 선포식
- 학습 문제 : 우리 반 AI 약속을 다른 사람에게 알릴 자료를 만들어 봅시다.
- slug : `pledge-board`
- 산출 경로 : `out/webapp/L08/index.html`

## 무엇을 하는 앱인가

확정한 약속을 알리는 캠페인 문구를 만듭니다. AI 문장을 어디에서 어떻게 고쳤는지 남기고, 표기표 네 칸을 채워야 현수막이 게시판에 올라갑니다.

## 화면

1. 이야기 : 확정한 약속을 학교에 알리는 캠페인이 시작됩니다. 읽고 나서 "현수막이 올라가지 않아요. 표기표가 비어 있어요. 무엇을 채울까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 광장 : 오늘 할 일을 한눈에 봅니다.
3. 역할 나누기 : 모둠에서 누가 무엇을 맡을지 정합니다.
4. 문구 공방 : 캠페인 문구를 만듭니다. AI가 내놓은 문장을 그대로 쓰지 않고 손봅니다.
5. 고친 곳 남기기 : AI 문장에서 무엇을 어떻게 고쳤는지 적습니다.
6. 표기표 : AI가 한 일과 우리가 한 일을 네 칸에 적습니다. 네 칸을 채우지 않으면 현수막이 올라가지 않습니다.
7. 게시판 : 교사 승인을 받은 현수막이 게시판에 올라갑니다.

## 교사 화면

게시 승인·반려, 활용 표기 누락 확인

## 이 앱만의 규칙

이미지 업로드 기능은 두지 않는다. 실물 자료는 인쇄물과 교사 화면 공유로 나눈다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/pledge-board/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 학생 얼굴·이름이 드러나는 자료는 올리지 않는다.
- 생성형 이미지 도구는 교사 계정으로만 쓴다.
- 게시판은 교사 승인 후 공개한다.

## 기기가 없을 때

기기가 부족하면 손그림 포스터로 제작하고, 활용 표기표만 웹앱에 등록한다.
