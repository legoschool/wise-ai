- 차시 : 11차시 AI for Good 프로젝트(1)
- 학습 문제 : 우리 생활과 지역의 문제를 찾고 AI로 도울 수 있는지 판단해 봅시다.
- slug : `good-project-board`
- 산출 경로 : `out/webapp/L11/index.html`

## 무엇을 하는 앱인가

마을 문제 후보를 올리고 누가·언제·무엇 때문에를 채워 한 문장으로 좁힙니다. 좁힘 눈금이 3에 닿아야 판정실과 설계실이 열립니다. 순서가 곧 배움입니다.

## 화면

1. 이야기 : 우리 마을 문제를 찾는 연구소에 들어갑니다. 읽고 나서 "게시판에 학교 앞이 위험해요라는 신고가 붙었어요. 무엇부터 할까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 좋은문제 연구소 : 오늘 밟을 연구 순서를 한눈에 봅니다.
3. 관찰대 : 후보 문제 세 개를 올리고 점수를 매깁니다.
4. 좁히기 작업대 : 누가·언제·무엇 때문에를 채우면 한 문장이 조립됩니다. 좁힘 눈금이 3에 닿아야 다음이 열립니다.
5. 판정실 : 이 문제에 AI를 써도 되는지 신호등으로 판정합니다.
6. 역할 나누기 : 모둠에서 누가 무엇을 맡을지 정합니다.
7. 설계실 : 해결 절차를 네 단계로 설계합니다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/good-project-board/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다
