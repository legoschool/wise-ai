# 5차시 웹앱 구성안 : 보조·대행 분류판

- 차시 : 5차시 보조자일까, 대행자일까
- 학습 문제 : AI가 나를 도와주는 순간과 나를 대신하는 순간을 구분해 봅시다.
- slug : `helper-or-doer`
- 산출 경로 : `out/webapp/L05/index.html`

## 무엇을 하는 앱인가

정비원이 되어 장면 카드를 보조와 대행으로 가릅니다. 대행으로 나온 장면에 조건 한 줄을 붙여 보조로 고치고, 그 조건 문장이 6·7차시 약속의 재료가 됩니다.

## 화면

1. 이야기 : 보조와 대행이 뒤섞인 정비소에 정비원으로 들어갑니다. 읽고 나서 "조수 로봇 덜컹이가 손을 내밀어요. 자전거를 어떻게 할까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 정비소 : 오늘 할 정비 순서를 한눈에 봅니다.
3. 몸풀기 : 생각을 누가 했는지, 결과물을 누가 만들었는지 두 축을 익힙니다.
4. 판별대 : 장면 카드 열두 장을 보조·경계·대행으로 판정합니다.
5. 우리 반과 견주기 : 학급 집계를 보고 갈린 장면을 다시 이야기합니다.
6. 정비 작업대 : 대행으로 나온 장면에 조건 한 줄을 붙여 보조로 고쳐 봅니다.
7. 정비 수칙 : 고칠 때 쓴 조건 문장을 모아 우리 정비 수칙으로 남깁니다. 6·7차시 약속의 재료가 됩니다.

## 교사 화면

장면별 보조·대행 비율과 의견이 갈린 장면 표시

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/helper-or-doer/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 정답 맞히기가 아니라 근거 말하기에 초점을 둔다.
- 자기 경험을 밝히기 어려워하는 학생은 카드로만 참여하게 허용한다.
- 솔직하게 말한 학생을 지지해 준다.

## 기기가 없을 때

인쇄 장면 카드와 모둠 분류판만으로 진행하고, 학급 집계는 칠판 스티커로 대신한다.
