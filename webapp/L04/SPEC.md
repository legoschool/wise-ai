# 4차시 웹앱 구성안 : 정보 분류 카드

- 차시 : 4차시 내 정보는 안전할까
- 학습 문제 : AI에 넣어도 되는 정보와 넣으면 안 되는 정보를 가려 봅시다.
- slug : `info-sorter`
- 산출 경로 : `out/webapp/L04/index.html`

## 무엇을 하는 앱인가

정보 지킴이가 되어 카드 스물네 장을 나눕니다. 넣으면 안 되는 정보를 초록문으로 보내면 되돌리기 상자에 담기고, 그 상자는 열리지 않습니다. 한 번 넘어간 정보는 돌아오지 않는다는 것을 화면으로 겪습니다.

## 화면

1. 이야기 : 정보 지킴이 본부로 출동 요청이 들어옵니다. 읽고 나서 "친구 얼굴이 나온 사진을 AI에게 넣으려 해요. 어느 문으로 보낼까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 지킴이 본부 : 오늘 지나갈 방들을 한눈에 봅니다.
3. 훈련장 : 쉬운 카드 몇 장으로 분류 연습을 합니다.
4. 분류실 : 카드 스물네 장을 세 칸으로 나눕니다. 정답은 보여 주지 않습니다.
5. 열람실 : 카드가 열립니다. 넣으면 안 되는 정보를 초록문으로 보냈으면 되돌리기 상자에 담기고, 그 상자는 열리지 않습니다.
6. 조건 작성소 : 조건을 붙이면 써도 되는 정보에 조건 한 줄을 답니다.
7. 우리 반과 견주기 : 학급 집계를 보고 판단이 갈린 카드를 다시 이야기합니다.

## 교사 화면

카드별 학급 분류 분포와 의견이 갈린 카드 확인

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/info-sorter/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다
