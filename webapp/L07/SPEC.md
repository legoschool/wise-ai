# 7차시 웹앱 구성안 : 우리 반 AI 약속

- 차시 : 7차시 우리 반 AI 약속 만들기
- 학습 문제 : 우리 반이 함께 지킬 AI 약속 8조항을 만들어 봅시다.
- slug : `class-pledge`
- 산출 경로 : `out/webapp/L07/index.html`

## 무엇을 하는 앱인가

우리 반 AI 약속을 회의로 정합니다. 하지 마라로 쓴 조항은 교실 상황에 넣어 보면 막히고, 학생이 이런 조건이면 된다는 문장으로 직접 고칩니다. 제안을 모아 투표해 여덟 조항을 확정합니다.

## 화면

1. 이야기 : 우리 반 AI 약속을 정하는 회의가 열립니다.
2. 회의실 : 오늘 할 다섯 교시를 한눈에 봅니다.
3. 여덟 기준 우리 말로 : AI적정활용 여덟 기준을 우리 반이 쓰는 말로 바꿔 적습니다.
4. 조항 쓰기 : 지킬 조항을 직접 씁니다. 하지 마라로 쓴 문장은 교실 상황에 넣어 보면 막힙니다.
5. 제안 모으기 : 모둠이 낸 제안이 한자리에 모입니다.
6. 투표 : 제안에 표를 던집니다. 옳고 그름을 매기지 않고 표만 셉니다.
7. 묶기와 확정 : 비슷한 제안을 묶어 우리 반 약속 여덟 조항으로 확정합니다.

## 교사 화면

기준별 제안 목록, 투표 결과, 확정 조항 내려받기

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/class-pledge/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다
