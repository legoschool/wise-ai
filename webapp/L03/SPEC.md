# 3차시 웹앱 구성안 : 편향 관찰 갤러리

- 차시 : 3차시 AI도 편견을 가질까
- 학습 문제 : AI의 결과에 담긴 치우침을 찾고, 그 까닭을 데이터에서 찾아봅시다.
- slug : `bias-gallery`
- 산출 경로 : `out/webapp/L03/index.html`

## 무엇을 하는 앱인가

탐정이 되어 그림을 그려 주는 AI를 조사합니다. 열두 장을 직접 세어 치우침을 숫자로 확인하고, 사진 창고의 비율을 학생이 바꿔 그림이 따라 바뀌는 것을 봅니다. 편견을 직접 만들고 직접 없앱니다.

## 화면

1. 이야기 : 그림을 그려 주는 AI가 이상하다는 제보를 받고 탐정이 됩니다. 읽고 나서 "의사 그림 열두 장이 다 비슷하게 나왔어요. 무엇을 먼저 할까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 탐정 사무소 : 오늘 밟을 수사 순서를 한눈에 봅니다.
3. 짐작하기 : 의사 그림 열두 장을 그리면 남성이 몇 장 나올지 먼저 짐작해 봅니다.
4. 그림 공장 : 실제로 열두 장이 그려집니다. 짐작과 얼마나 달랐는지 화면에서 바로 봅니다.
5. 세어 보기 : 성별, 나이, 피부색을 직접 세어 표에 적습니다. 느낌이 아니라 숫자로 확인합니다.
6. 사진 창고 : 창고의 사진 비율을 학생이 바꿉니다. 비율을 고치면 나오는 그림이 따라 바뀝니다.
7. 마음 살피기 : 이 그림을 본 사람 가운데 누가 속상할지 짚어 보고 까닭을 적습니다.

## 교사 화면

사례별 학생 설명 문장을 모아 학급 화면으로 띄우기

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/bias-gallery/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 학생이 직접 이미지 생성 도구를 다루지 않는다. 교사 시연으로 한다.
- 특정 성별·직업·나라를 비하하는 표현이 나오지 않게 사전 확인한다.
- 결과를 비웃는 분위기가 되지 않게 한다.

## 기기가 없을 때

생성형 도구를 쓰지 않고, 교사가 미리 준비한 편향 사례 인쇄 카드로 동일한 관찰·설명 활동을 한다.
