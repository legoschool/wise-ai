# 12차시 웹앱 구성안 : 프로젝트 발표와 성찰

- 차시 : 12차시 AI for Good 프로젝트(2)
- 학습 문제 : 해결 결과물을 만들어 발표하고 12차시를 돌아봅시다.
- slug : `reflect-share`
- 산출 경로 : `out/webapp/L12/index.html`

## 무엇을 하는 앱인가

결과물 부스를 차리고 표기표를 만듭니다. 프로젝트를 만든 여덟 단계를 우리·함께·AI로 나누면 표기 문장이 자라나고, 마지막 결정을 AI로 두면 화면이 되묻습니다.

## 화면

1. 이야기 : 열두 시간을 마무리하는 전시가 열립니다. 읽고 나서 "전시장 문을 엽니다. 첫 손님 몽이에게 무엇을 먼저 말할까요?" 보기 세 개 가운데 하나를 고릅니다. 고르면 바로 답이 나오지 않고 잠깐 뜸을 들인 뒤 벌어진 일이 열립니다. 옳고 그름을 매기지 않습니다.
2. 전시장 : 오늘 할 일을 한눈에 봅니다.
3. 부스 차리기 : 우리 모둠 결과물을 소개하는 부스를 꾸립니다.
4. 표기표 만들기 : 프로젝트를 만든 여덟 단계를 우리·함께·AI로 나눕니다. 마지막 결정을 AI로 두면 화면이 되묻습니다.
5. 약속 점검 : 우리 반 약속 가운데 어떤 조항을 지켰는지 표시합니다.
6. 전시장 둘러보기 : 다른 모둠 부스를 돌아봅니다.
7. 돌아보기 : 첫 시간과 지금 내 생각이 어떻게 달라졌는지 적고 사후 설문으로 이어집니다.

## 교사 화면

모둠 발표 순서, 성찰문 모음, 사후 설문 응답률

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/reflect-share/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다
